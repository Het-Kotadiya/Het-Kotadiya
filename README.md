**Selected work**

- **[Words vs Actions: an LLM catches broken promises, not planned lies](https://apartresearch.com/sprints/projects/words-vs-actions-an-llm-catches-broken-promises-not-planned-lies-s2hc)**
  Apart Research, AI Collusion Research Sprint (Oct 2026) · [code](https://github.com/Het-Kotadiya/lie-or-change-of-mind)
  Can an LLM monitor tell a planned lie from an honest change of mind? Seeing an agent's words and actions, it beat chance (AUROC 0.79 and 0.71). But I found no evidence it could separate planned liars from mind-changers at this sample size (AUROC 0.47–0.63), and it flagged 11 of 15 honest mind-changers as liars.

- **Defense in depth against LLM jailbreaks** (security capstone, DePaul)
  Tested three safety layers on Vicuna-7B against 282 published JailbreakBench attacks. An input filter plus an output filter cut attack success from 95% to 10%, while wrongly blocking 10% of harmless requests. A hardened system prompt backfired on this small model, raising wrongful blocks from 4% to 27%.
